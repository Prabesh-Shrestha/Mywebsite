Research context

My research-assistant work includes human-subject experiments using EEG and ballistocardiography. Alongside the experimental work, I contribute to the electronics and embedded systems used for data collection and retrieval.

Firmware

  • Developed custom firmware for an ESP-based data-recording system.
  • Added support for wireless reflashing.
  • Implemented custom memory repartitioning for the recording platform.

Hardware

I redesigned schematics for the data-retrieval system and processed the design for PCB manufacturing, tying the embedded firmware work back to the physical research instrumentation.
