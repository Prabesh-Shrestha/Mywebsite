AgroAssist.

An agriculture automation suite combining a multi-node sensor network, cloud data processing, machine-learning recommendations, and real-time monitoring.

TypeIoT + ML
Timeline2022–2024
CloudAWS
MLAzure ML

Sensor network

AgroAssist used a multi-node IoT sensing network to collect live soil moisture, temperature, and humidity data. The project connected physical field measurements to cloud processing and a monitoring interface.

Cloud + ML

  • Used AWS for data processing and storage.
  • Used Azure ML for seed recommendation and plant-disease detection.
  • Developed an online dashboard for real-time monitoring and decision support.
