Scalable 3D-printer infrastructure.

An OctoPrint-based makerspace printer-farm system using Dockerized services, custom plugins, and secure proxying behind university firewalls.

ContextIngram Hall Makerspace
RoleStudent Technician
Timeline2025–Present
FocusMachine infrastructure

Problem space

A shared makerspace needs printer infrastructure that can support multiple machines without treating each printer as an isolated workstation. My work focused on operating the printer fleet through OctoPrint and building the supporting software environment around it.

The resume documents this as a scalable 3D-printer farm built with OctoPrint, Dockerized services, custom plugins, and secure proxying behind university firewalls.

What I built

  • Built and operated a multi-printer OctoPrint environment.
  • Used Dockerized services to keep supporting software organized and repeatable.
  • Worked with custom OctoPrint plugins as part of the deployment.
  • Handled secure proxying so the system could operate within university network constraints.
